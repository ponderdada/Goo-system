# 投資決策系統 (Goo System)

每日自動分析市場狀況，產出投資配置建議報告。

## 系統架構

```
┌─────────────────────────────────────────────┐
│           run_daily.py (每日入口)             │
├──────────┬──────────────┬───────────────────┤
│ 模組一    │   模組二      │     模組三         │
│ 現金配置  │ 指數vs個股    │  新聞驅動選股      │
│          │              │                   │
│ VIX指數   │ 市場寬度      │ 價量異常偵測       │
│ 均線趨勢  │ 波動度分析    │ 動能/RSI分析      │
├──────────┴──────────────┴───────────────────┤
│          報告產生器 (HTML/文字)               │
└─────────────────────────────────────────────┘
```

### 模組一：現金 vs 投資配置
- 根據 VIX 恐慌指數決定基礎現金比例
- 根據大盤是否高於 200 日均線調整

### 模組二：指數 vs 個股配置
- 根據市場寬度（漲跌比）判斷配置
- 個股波動度過高時自動轉向指數

### 模組三：新聞驅動選股
- 以價量異常作為消息面代理指標
- 結合動能、RSI、波動率綜合評分
- 篩選出最具上漲潛力的個股

## 安裝

```bash
pip install -r requirements.txt
```

## 使用

```bash
# 產生 HTML 報告（預設）
python run_daily.py

# 產生純文字報告
python run_daily.py --text

# 不自動開啟瀏覽器
python run_daily.py --no-open
```

## 設定

所有參數皆可在 `config/settings.yaml` 中調整，包括：
- VIX 閾值與現金比例
- 指數/個股配置比例
- 觀察清單（股票池）
- 篩選條件

## 免責聲明

本系統僅供參考，不構成任何投資建議。投資有風險，決策請自行判斷。
